# SIH26127 — City-Wide AI Engine for Multi-Camera ANPR Trajectory Tracking & Urban Traffic Analytics

An end-to-end intelligent traffic management system designed to track vehicle trajectories across multiple camera feeds using Automatic Number-Plate Recognition (ANPR) and provide real-time urban traffic analytics on a live web dashboard.

---

## Project Purpose
The system solves the problem of city-wide tracking and traffic management. By processing feeds from multiple cameras, it extracts license plates, matches them across locations to trace full vehicle journeys, and highlights high-congestion zones in real-time.

---

## Core Pipeline Components

### 1. Detection & ANPR Engine
* **Input:** Raw traffic video files simulating discrete camera feeds.
* **Processing:**
    * Vehicle bounding box detection using pretrained YOLOv8 models.
    * Intra-camera vehicle tracking utilizing ByteTrack or DeepSORT.
    * License plate cropping and character extraction via EasyOCR.
    * Text normalization (uppercase, white-space stripping) and high-confidence filtering.
* **Output:** Framewise vehicle metadata files (`detections.json`) separated by camera.

### 2. Re-Identification & Trajectory Engine
* **Input:** Multi-camera vehicle log data generated by the detection stage.
* **Processing:**
    * Cross-camera trajectory stitching using exact string matching of normalized plate texts.
    * Chronological sorting of vehicle appearances across tracking spots.
    * Calculation of confidence scores based on cumulative OCR reliability metrics.
    * Compilation of traffic metrics: average travel times between points and camera-specific vehicle counts.
* **Output:** Full structural journey records (`trajectories.json`) alongside traffic analytics files.

### 3. Backend API & Dashboard UI
* **Input:** Compiled trajectory profiles and spatial camera configuration details.
* **Processing:**
    * A lightweight FastAPI or Flask application serving endpoints for analytics and vehicle searches.
    * A Leaflet or Mapbox interactive map plotting static camera locations.
    * Animated marker paths illustrating vehicle movement across tracking nodes sequentially.
    * Dynamic bar or line charts highlighting real-time location volume metrics.
* **Output:** A live management dashboard featuring license plate searches and live congestion overviews.

---

## Central Data Specifications

### Detections Layout (`detections.json`)
Transfers localized crop data per frame per camera to the trajectory assembler. It records frame IDs, tracking indices, bounding box arrays, bounding plate text values, and categorization fields.

### Trajectories Layout (`trajectories.json`)
Feeds complete chronological trip information to the frontend visualization dashboard. It matches a unique license plate to its ordered chain of camera timestamps to build route paths seamlessly.

### Spatial Coordinates Layout (`camera_locations.json`)
A configuration lookup mapping each unique camera identification tag to its static real-world latitude and longitude coordinates.
